01Экономика внимания

Каждый прямоугольник на этой странице — чья-то зона ответственности. Кроме одного.

Заголовок, цена, кнопка, характеристики, отзывы, рекомендации — каждый элемент оптимизируют отдельные команды, потому что конверсия PDP напрямую зависит от того, как используется каждый участок экрана. Главное фото из этой системы выпадает: занимает наибольшую площадь, но не конкурирует за внимание как навигационный или рекламный элемент.

02Кликабельные сегменты

Одна фотография — N независимых рекламных мест.

При публикации карточки фото прогоняется через сегментацию. Каждый объект в кадре получает собственный контур, собственный URL и собственную строчку в отчёте. Один и тот же кадр одновременно работает как кросс-сейл, апсейл, лукбук и партнёрская интеграция — без новых скроллов и модалок.

03Существующее vs предлагаемое

Точка и прямоугольник — весь словарь shoppable-фото на сегодня.

Текущие решения (dot-маркер, AABB-тег) статичны, геометрически грубы и визуально нейтральны. Они не возобновляются при смене кадра и проигрывают в борьбе за внимание любому анимированному соседу. Орбита привязана к контуру объекта, перезапускается при свайпе и сама конкурирует за взгляд.

Сегодня · static marker

Точка / AABB-тег

Статичная иконка поверх изображения. Контур игнорируется, реакции на смену кадра нет, в эстетике витрины не участвует.
SDF Orbit · proposed

Орбита вдоль контура

Анимация совпадает с формой объекта, перезапускается при каждом свайпе галереи, настраивается под визуальный язык категории.
04Технология

SDF — поле расстояний, повторяющее форму.

Контур сегмента хранится не как полигон и не как маска, а как Signed Distance Field: каждому пикселю — расстояние до границы со знаком. Эффект на GPU читает это поле одним сэмплированием и рисует полосу-орбиту, движущуюся вдоль изолинии в режиме ping-pong.

01 · INPUT

Сегментация → маска

Модель сегментации возвращает бинарную маску каждого объекта в кадре: «внутри / снаружи».

02 · TRANSFORM

SDF + размытие

Маска превращается в поле расстояний и сглаживается одним проходом, чтобы убрать зубцы и микроартефакты.

03 · RENDER

Орбита на изолинии

Полоса = пиксели, у которых SDF = d₀(t). d₀ ходит вперёд-назад через кубический Безье — это и есть «ping-pong».

shaders/wave.glsl
// волна = пиксели, где |SDF − centerOffset(t)| < halfW
float waveBand(float d, float centerOffsetPx, float halfW){
    float aa = max(fwidth(d), 0.75);
    float m1 = smoothstep(centerOffsetPx - halfW - aa,
                          centerOffsetPx - halfW + aa, d);
    float m2 = 1.0 - smoothstep(centerOffsetPx + halfW - aa,
                                centerOffsetPx + halfW + aa, d);
    return m1 * m2;
}

// центр полосы движется вперёд-назад через кубический Безье
float s          = fract(uTime * uWaveSpeed);
float halfInter  = (s < 0.5) ? cubicBezierEase(s*2.0, c1, c2)
                            : cubicBezierEase(2.0 - s*2.0, c1, c2);
float centerOffset = uWaveBasePx + uWaveAmpPx * (2.0*halfInter - 1.0);

05Пять эффектов · один корень

Пять визуальных стилей, наследующих один анимационный движок.

Все эффекты строятся поверх double ping-pong: меняется только последний шаг — то, что именно рисуется в полосе-орбите. Это позволяет добавлять новые стили без переработки геометрической или анимационной логики.

EFFECT 01

Dot Grid

Сетка точек, плотность и яркость которых зависят от близости к орбите.

EFFECT 02

Drop Grid

Преломляющие капли вдоль контура — мягкое, «жидкое» прочтение орбиты.

EFFECT 03

Neon Ring

Светящееся кольцо вдоль контура с соседними связями — самый «гэмблинговый» стиль.

EFFECT 04

Dither Grid

Дизерная решётка, чья плотность нарастает по мере приближения к изолинии.

EFFECT 05

Text Grid

Глифы из SDF-атласа — катакана, латиница, кастом — выкладываются по орбите.

06Пайплайн

От загрузки фото до строки в отчёте по выручке.

Визуал — только верхний слой. За ним стоит обычная воронка атрибуции: каждое касание зоны рождает событие click(segment_id, product_id, position, t), которое попадает в аналитическую шину и собирается в отчёт «выручка на сегмент / на фото / на товар».

07Pilot

Подключите SDF Orbit к одной категории. Соберите первые числа за две недели.

Мы ищем 1–2 маркетплейса или бренда для пилотного запуска: одна категория, одна полка, одно фото с орбитой. Сравним метрики кликов и выручки против контрольной группы. Если работает — масштабируем; если нет — заметка в блоге об интересном эксперименте.
